Using the HeFQUIN PG Connector Command-Line Programs

HeFQUIN provides two command-line programs for working with Property Graphs through the PG Connector:

  • hefquin-pg - can be used to execute SPARQL-star queries over a Property Graph. The query is translated into openCypher and sent to the Property Graph store.
  • hefquin-pgmat - can be used to materialize the RDF-star view of a Property Graph by applying an LPG-to-RDF-star configuration.

Both programs currently support Neo4j as the Property Graph store.

The hefquin-pg program can be used to execute a SPARQL-star query over a Property Graph. For example, assuming that ExampleQuery.rq contains the SPARQL-star query to execute and ExampleLPG2RDF.ttl contains the LPG-to-RDF-star configuration to use, the program can be invoked as follows: 

hefquin-pg --query=ExampleQuery.rq --lpg2rdfconf=ExampleLPG2RDF.ttl --endpoint=http://localhost:7474/db/neo4j/tx/commit

The --query argument refers to a file containing the SPARQL-star query to be executed. The --lpg2rdfconf argument refers to an RDF document containing the LPG-to-RDF-star configuration that defines the RDF-star view of the Property Graph. The --endpoint argument specifies the HTTP endpoint at which the Neo4j instance accepts Cypher queries.

The hefquin-pgmat program can be used to materialize the RDF-star view of a Property Graph. It applies an LPG-to-RDF-star configuration and produces an RDF-star graph representing the Property Graph according to that configuration.

For example, assuming that ExampleLPG2RDF.ttl contains the LPG-to-RDF-star configuration, the program can be invoked as follows: 

hefquin-pgmat --lpg2rdfconf=ExampleLPG2RDF.ttl --endpoint=http://localhost:7474/db/neo4j/tx/commit

The --lpg2rdfconf argument refers to an RDF document containing the LPG-to-RDF-star configuration to apply. The --endpoint argument specifies the HTTP endpoint of the Neo4j instance from which the Property Graph is read.

Further arguments can be passed to both programs, which are described in detail below. You can also have the list of supported arguments printed by executing the programs with the argument --help. 

hefquin-pg --help
hefquin-pgmat --help

Arguments Exclusive to hefquin-pg

Query-Related Arguments

--query=<file> (mandatory argument)

Refers to a file containing the SPARQL-star query to be executed over the Property Graph.

--base=<URI>

Provides a base URI for the SPARQL-star query. Relative IRIs in the query are resolved against this base URI.

Result-Related Arguments

--results=<format>

Specifies the format in which the query results are printed. For result sets, supported formats include the following:

  • TEXT - Simple text output in table form (default).
  • JSON - Standard JSON format.
  • XML - Standard XML format.
  • CSV - Standard CSV format.
  • TSV - Standard TSV format.

For RDF graphs, an RDF serialization can be specified.

--printCypherQuery

Prints the openCypher query or queries produced by the SPARQL-star query translation process.

--suppressResultPrintout

Prevents the query result from being printed to standard output.

--skipExecution

Skips execution of the generated query while still performing the query translation and creating the corresponding execution plan.

LPG-to-RDF Mapping Arguments

--naive

Disables the inference of certain RDF-star terms during the translation of basic graph patterns into openCypher, resulting in a naive translation of the query.

--disableVariableReplacement

Disables variable replacement during the translation of the generated openCypher query.

--disablePathMerging

Disables path merging during the translation of the generated openCypher query.

Endpoint-Related Arguments of Both Programs

-e   --endpoint=<URI> (mandatory argument)

Specifies the HTTP endpoint of the Neo4j instance to which hefquin-pg sends generated openCypher queries and from which hefquin-pgmat reads the Property Graph.

-u   --username=<username>

Specifies the username used for authentication with the Neo4j endpoint.

-p   --password=<password>

Specifies the password used for authentication with the Neo4j endpoint.

LPG-to-RDF Mapping Arguments of Both Programs

--lpg2rdfconf=<file>

Refers to a file containing an RDF description of the LPG-to-RDF-star configuration. The configuration defines how the Property Graph is represented as an RDF-star view.

The document must contain an RDF-based description of an LPG-to-RDF-star configuration using the LPG-to-RDF configuration vocabulary.

--lpg2rdfconfURI=<URI>

Specifies the URI of the LPG-to-RDF-star configuration to use. This argument can be used when the configuration file contains multiple configurations.

Experiments-Related Arguments of Both Programs

--time

Measures and reports the time taken by the operation.

Other Arguments of Both Programs

--help

Prints a list of all supported arguments and terminates. If this argument is given, all other arguments are ignored.
